## 🔍 ЗАДАЧА 1: ФИЛЬТРЫ ВАКАНСИЙ

Реализуй клиентскую фильтрацию массива `MOCK_VACANCIES`

---

### 🔎 0. Поиск по названию (Search)

**Тип UI:** текстовый инпут в шапке страницы (не в сайдбаре)  
**Поле в моке:** `title`  
**Поведение:** регистронезависимый поиск по подстроке

### 💼 3. Формат работы (Work Format)

**Тип UI:** чекбоксы

| Лейбл    | Значение в моке |
| -------- | --------------- |
| Офис     | `office`        |

### 📅 4. Опыт работы (Experience)

**Тип UI:** чекбоксы

| Лейбл         | Значение в моке |
| ------------- | --------------- |

---

### ⚙️ 6. Технологии (Technologies)

**Тип UI:** чекбоксы  
**Поле в моке:** `technologies[]`

---

### Требования к фильтрации:

✅ Активные фильтры отображаются как **теги** с кнопкой удаления

✅ Кнопка **«Сбросить всё»** появляется когда активен хотя бы один фильтр

✅ Количество найденных вакансий обновляется при изменении фильтров

✅ При отсутствии результатов показывается заглушка «Вакансий не найдено»

✅ Несколько чекбоксов одного фильтра работают как **OR** (вакансия подходит, если совпадает хотя бы одно значение)

✅ Разные фильтры работают как **AND** (вакансия должна совпасть по всем активным фильтрам)

## 📍 ЗАДАЧА 2: КНОПКА ЛОКАЦИИ НА КАРТОЧКЕ

На каждой карточке вакансии добавь кнопку с иконкой 📍 (или «Офис на карте»).

При клике на кнопку:

1. Открывается **модальное окно**
2. В модальном окне — **встроенная карта Яндекс** с адресом офиса
3. Модальное окно закрывается по кнопке ✕ или клику на фон

### Адреса офисов BCC:

| Город  | Адрес                           |
| ------ | ------------------------------- |
| Almaty | просп. Аль-Фараби, 77/7, Алматы |
| Astana | ул. Кабанбай Батыра, 11, Астана |

### Встраивание Яндекс Карты (без API ключа):

```tsx
<iframe
  src="https://yandex.ru/map-widget/v1/?text=Алматы%2C+просп.+Аль-Фараби%2C+77/7"
  width="100%"
  height="400"
  frameBorder="0"
  allowFullScreen
/>
```
