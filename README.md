## 🗂️ МОК-ДАННЫЕ

Мок-данные уже подготовлены в `src/shared/mocks/transactions.ts` — **50 операций** по 8 датам:

| Поле           | Тип / Значения                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| `id`           | `string` — уникальный идентификатор                                                                      |
| `date`         | `string` — формат `'YYYY-MM-DD'`                                                                         |
| `number`       | `string` — короткий (`'23'`) или длинный (`'003434542'`) → длинный (>6 симв.) отображай как `...{число}` |
| `name`         | `string` — тип операции (длинный → обрезай с `…`)                                                        |
| `counterparty` | `string` — название организации (длинное → обрезай с `…`)                                                |
| `bin_iin`      | `string \| null` — `null` → отображай как `–`                                                            |
| `amount`       | `number` — форматируй пробелами как разделитель тысяч + символ валюты (`₸` / `₽` / `$`)                 |
| `currency`     | `'KZT' \| 'RUB' \| 'USD'`                                                                               |
| `status`       | `'partially_signed' \| 'executed' \| 'processing' \| 'created' \| 'error'`                              |

Импортируй в своих компонентах:

```typescript

```

## 📊 ЗАДАЧА 2: БЛОК «ОПЕРАЦИИ»

Реализуй таблицу операций, точно следуя дизайну в Figma.

---

### Таблица

Колонки (в порядке слева направо):

| Колонка        | Поле в моке   | Правило отображения                                              |
| -------------- | ------------- | ---------------------------------------------------------------- |
| **Статус**     | `status`      | Иконка + цветной лейбл (см. таблицу статусов ниже)              |
| **Номер**      | `number`      | Если длина > 6 символов — отображай как `...{number}`            |
| **Наименование** | `name` + `counterparty` | Две строки: название жирным, организация светлым; обе обрезаются с `…` |
| **БИН/ИИН**   | `bin_iin`     | `null` → отображай как `–`                                       |
| **Сумма**      | `amount` + `currency` | Число с пробелами как разделитель тысяч + символ: `₸` (KZT), `₽` (RUB), `$` (USD) |

### Статусы:

| Значение            | Лейбл               | Цвет    |
| ------------------- | ------------------- | ------- |
| `partially_signed`  | Частично подписано  | жёлтый  |
| `executed`          | Исполнено           | зелёный |
| `processing`        | В обработке         | синий   |
| `created`           | Создано             | серый   |
| `error`             | Ошибка              | красный |

### Группировка по дате:

Строки группируются по полю `date`. Перед каждой группой — заголовок с датой в формате `«D MMMM YYYY»` (например, `7 февраля 2024`).

---

### Фильтры

Три фильтра в шапке блока:

| Фильтр      | Тип        | Значения                                                               |
| ----------- | ---------- | ---------------------------------------------------------------------- |
| **Статус**  | Выпадающий | `partially_signed`, `executed`, `processing`, `created`, `error`       |
| **Валюта**  | Выпадающий | `KZT`, `RUB`, `USD`                                                    |
| **Сегодня** | Чип-тоггл  | Включён → показывать только строки с `date === сегодня` (для тестирования используй дату `2024-02-07`) |

Активные фильтры работают как **AND** (строка должна совпасть по всем включённым фильтрам).

---

### Пагинация

- **10 строк на страницу** (не считая заголовков-дат)
- Заголовки групп дат не разрываются — если первая строка группы уходит на следующую страницу, заголовок уходит вместе с ней
- Показывай номера страниц + кнопки «‹» и «›»
