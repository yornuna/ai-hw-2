### Требования к фильтрации:

✅ Активные фильтры отображаются как **теги** с кнопкой удаления

✅ Кнопка **«Сбросить всё»** появляется когда активен хотя бы один фильтр

✅ Количество найденных вакансий обновляется при изменении фильтров

✅ При отсутствии результатов показывается заглушка «Вакансий не найдено»

✅ Несколько чекбоксов одного фильтра работают как **OR** (вакансия подходит, если совпадает хотя бы одно значение)

✅ Разные фильтры работают как **AND** (вакансия должна совпасть по всем активным фильтрам)

## 🗺️ Настройка Яндекс Карт

Карты используются в **Задаче 2** (модальное окно на карточке вакансии) и **Задаче 3** (блок Office Locations).

### 1. Создай аккаунт и получи API ключ

1. Зайди на https://developer.tech.yandex.ru/
2. Войди через аккаунт Яндекс (или создай его)
3. Нажми **«Подключить API»** → выбери **«JavaScript API»**
4. Заполни форму → получи API ключ

### 2. Добавь ключ в переменные окружения

Создай файл `.env.local` в корне проекта:

```
NEXT_PUBLIC_YANDEX_MAPS_API_KEY=твой-ключ-здесь
```

> `.env.local` уже добавлен в `.gitignore` — ключ не попадёт в репозиторий.

### 3. Установи библиотеку

```bash
npm install @pbe/react-yandex-maps
```

### 4. Подключи провайдер в layout

Оберни приложение провайдером `YMaps` в `app/layout.tsx`:

```tsx
import { YMaps } from "@pbe/react-yandex-maps";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ru">
      <body>
        <YMaps query={{ apikey: process.env.NEXT_PUBLIC_YANDEX_MAPS_API_KEY, lang: "ru_RU" }}>
          {children}
        </YMaps>
      </body>
    </html>
  );
}
```

### 5. Используй карту в компонентах

```tsx
import { Map, Placemark } from "@pbe/react-yandex-maps";

// state (контролируемый) — метка перемещается при смене selectedOffice
<Map
  state={{ center: [selectedOffice.lat, selectedOffice.lng], zoom: 15 }}
  width="100%"
  height="450px"
>
  <Placemark geometry={[selectedOffice.lat, selectedOffice.lng]} />
</Map>
```

> Координаты офисов (`lat`, `lng`) берутся из `MOCK_OFFICES` в `src/shared/mocks/offices.ts`.
